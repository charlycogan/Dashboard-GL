# Dashboard de gestion locative

Compagnon de travail quotidien pour gestionnaire locatif : échéancier central, congés locataires, arrêtés de compte / restitution du dépôt de garantie, et suivi d'objectifs (« Mes stats »).

## Lancement

Téléchargez le fichier **`dashboard-gestion-locative.html`**, puis **double-cliquez dessus** : il s'ouvre dans votre navigateur, c'est tout.

Rien à installer, aucune connexion Internet nécessaire. Vos données restent uniquement sur votre ordinateur, dans votre navigateur.

## Bon à savoir

- Utilisez toujours le **même navigateur** sur le **même poste** pour retrouver vos données.
- Pensez à cliquer régulièrement sur **« Exporter la sauvegarde »** : un fichier `.json` est téléchargé, que vous pourrez recharger via **« Importer une sauvegarde »** (en cas de changement de poste ou de navigateur, par exemple). Un rappel s'affiche si aucune sauvegarde n'a été faite depuis 7 jours.
- Évitez la navigation privée : les données y sont effacées à la fermeture.
